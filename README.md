HPC Python Homework Project
Social Support and Stress Analysis in a Hypothetical IPV Dataset

Author: Jacklyn
Date: October 2026

Project Overview
----------------
This project demonstrates a reproducible Python workflow on the Great Lakes high-performance computing (HPC) cluster. The analysis uses a hypothetical dataset related to intimate partner violence (IPV) research and examines the relationship between social support and stress among ten participants.

The project was executed as a SLURM batch job using a Conda environment created from an environment.yml file. Results were generated on a Great Lakes compute node and saved to output files for verification and reproducibility.

Analysis Performed
------------------
The Python program:

- Creates a hypothetical dataset containing social support and stress scores.
- Calculates the sample size (N).
- Calculates the average social support score.
- Calculates the average stress score.
- Computes the correlation between social support and stress.
- Generates a brief interpretation of the findings.
- Saves the results to a CSV file named ipv_summary.csv.

Files Included
--------------
ipv_analysis.py
    Python program used to perform the analysis.

environment.yml
    Conda environment specification required to reproduce the software environment.

run_job.sh
    SLURM batch script used to execute the program on Great Lakes.

reflection.txt
    Written reflection describing the project workflow and verification steps.

logs/
    Standard output and error files generated by the SLURM job.

results/
    Program output files, saved job ID, and SLURM accounting record.

Reproducibility
---------------
To reproduce this project:

1. Create the Conda environment from environment.yml.
2. Activate the environment.
3. Submit run_job.sh using SLURM.
4. Review the generated logs and results files.

Educational Purpose
-------------------
This project was created for instructional purposes as part of an HPC workflow assignment. The dataset is entirely hypothetical and does not contain real participant information. The analysis is intended to demonstrate reproducible computing practices rather than draw scientific or clinical conclusions.
